# VibrationHookLSPatch

LSPatch module untuk mendeteksi event/getaran Android dan meneruskannya ke Tasker.

## Tujuan

Membuat Tasker dapat merespons event vibration tanpa Shizuku atau root.

## Status

Experimental.

## Instalasi

1. Patch aplikasi target menggunakan LSPatch.
2. Instal APK hasil patch.
3. Aktifkan module.
4. Jalankan aplikasi target.
5. Gunakan Tasker untuk menerima event vibration.

## Catatan

Project ini masih dalam tahap pengembangan.
